Hướng dẫn lấy Gemini API Key miễn phí

  1. Truy cập Google AI Studio tại địa chỉ: https://aistudio.google.com/app/apikey
  2. Đăng nhập bằng tài khoản Google cá nhân của bạn.
  3. Bấm nút "Create API key", sao chép mã bắt đầu bằng AIza... và dán vào ô trên.
  4. Khóa của bạn được lưu trực tiếp trong trình duyệt này và chỉ gửi trực tiếp tới máy chủ generativelanguage.googleapis.com của Google khi bạn bấm nút tạo AI.

☁️ Đồng bộ tự động (Không cần xuất/nhập JSON thủ công)

Bình thường trên cùng 1 trình duyệt, dữ liệu đã tự lưu 100%. Nếu bạn muốn tự động đồng bộ qua đám mây (giữa máy tính & điện thoại) hoặc tự ghi đè trực tiếp vào 1 file trên máy tính, hãy chọn 1 trong 2 cách dưới đây:

Trạng thái: Lưu cục bộ trình duyệt

Cách 1: Đồng bộ Đám mây tự động (GitHub Gist - Miễn phí)

Tự động tải dữ liệu mới nhất khi mở app và tự động đẩy lên mây mỗi khi bạn thêm từ, ôn tập hay sửa cài đặt (kể cả API Key). Dùng chung được trên cả Điện thoại và Máy tính.

Cách lấy mã GitHub Token miễn phí trong 30 giây

  1. Đăng nhập GitHub, vào https://github.com/settings/tokens/new
  2. Ô Note điền HocTiengTrung, mục Expiration chọn No expiration.
  3. Tick chọn duy nhất ô gist (Create gists) rồi bấm Generate token ở cuối trang.
  4. Copy mã ghp_... dán vào ô trên và bấm Lưu & Đồng bộ lên mây ngay. На thiết bị thứ 2, chỉ cần nhập cùng Token và Gist ID này là 2 máy tự đồng bộ!

Cách 2: Tự động ghi thẳng vào 1 file trên máy tính (Google Drive / OneDrive / Ổ cứng)

Dành cho Chrome / Edge trên máy tính: Bạn chỉ cần chọn 1 file .json trên máy (hoặc trong thư mục Google Drive / iCloud / OneDrive). Từ đó về sau, mỗi khi bạn học hay thêm từ, ứng dụng tự động ghi đè trực tiếp vào file đó mà không bao giờ hỏi tải xuống nữa.
